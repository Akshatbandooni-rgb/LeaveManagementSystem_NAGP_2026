// Key Flow Sequences

Leave Approval Flow
1
Manager sends PATCH /leaves/:id/approve with JWT Bearer token
→ Gateway :3000
2
Gateway validates JWT, strips Authorization header, adds X-User-Id, X-User-Role, X-Internal-Secret, X-Correlation-Id
→ Consul lookup: leave-service
3
Gateway resolves Leave Service address from Consul, fires request through Opossum circuit breaker
→ Leave Service :3002
4
Leave Service verifies X-Internal-Secret, reads user context from headers
5
Service checks: leave exists → manager owns it → status is PENDING
6
Atomic synchronous block: deductBalance() then update status APPROVED — no await between them
7
Returns 200 APPROVED to client
⟶ RabbitMQ: leave.approved (async, non-blocking)
8
Notification Service consumes event, logs structured approval notification with correlationId
New Employee Balance Init Flow
1
Manager sends POST /users with new employee data via Gateway
→ Gateway → User Service :3001
2
User Service hashes password with bcrypt, saves to in-memory Map
3
User Service checks role === EMPLOYEE, publishes user.created event to RabbitMQ
4
Returns 201 to client immediately — does NOT wait for balance init
⟶ RabbitMQ: user.events exchange
5
Leave Service consumer receives user.created from queue leave-service.user.created
6
Calls balanceRepo.initializeBalance(userId) — idempotent, checks if exists first
7
Balance initialized: CASUAL: 12, SICK: 10, PRIVILEGE: 15
8
Message acked — if consumer was down, RabbitMQ held the message and delivers on recovery

// Technology Stack

Node.js 20
Runtime — single-threaded event loop enables safe synchronous in-memory mutations
Express.js
HTTP framework — middleware chain, routing, error handler pattern
TypeScript
Strict mode — compile-time safety for domain models and layer boundaries
Zod
Request validation — TypeScript-first schemas, type inference, field-level errors
RabbitMQ
Message broker — async event delivery, durable queues, at-least-once delivery
Consul
Service registry — dynamic address resolution, health checking, UI at :8500
Jaeger + OTel
Distributed tracing — auto-instrumented HTTP spans, trace context propagation
Opossum
Circuit breaker — timeout 5s, threshold 50%, reset 30s, instant 503 on open
Pino
Structured logging — JSON output, correlationId on every line, log levels
amqp-conn-mgr
RabbitMQ client with auto-reconnect — handles startup race condition gracefully
jsonwebtoken
JWT signing (User Service) and verification (Gateway only) — HS256, 8h expiry
Docker Compose
Single command startup — 7 containers, shared network, health-check ordering
